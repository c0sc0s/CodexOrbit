# Project identity

`logo.png` is the approved Codex Orbit mark: a white dithered pixel planet, a compact stepped orbital path and a lime-green pixel star on a cobalt-blue background. It is independent of OpenAI's branding.

`banner.png` is the 3:1 README masthead shared by both languages. It pairs the same mark with the pixel-lettered title “Codex Orbit” and tagline “Your Codex. Your orbit.” The READMEs include localized alt text.

`icon.icns` is the macOS launcher asset derived from `logo.png`, containing 16, 32, 128, 256 and 512-point representations at 1× and 2×. Convert with macOS `sips` and `iconutil`; do not generate the launcher and README marks independently.

## Source artwork

The user-approved images were created with the built-in image generation tool. `codex-orbit-logo-pixel-v2.png` and `codex-orbit-banner-pixel.png` retain the selected originals. Preserve their composition when copying to the canonical asset names.

Use one consistent retro pixel-art treatment: square-pixel dithering, fine staircase outlines, cobalt blue, white and a restrained lime accent. Banner typography uses the same pixel style.
