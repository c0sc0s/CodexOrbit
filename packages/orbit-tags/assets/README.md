# Orbit Tags artwork

This directory contains pixel-art brand artwork for product presentation. The visual palette is cobalt blue, white and a lime-green accent; compositions use square-pixel dithering and stepped outlines.

The canonical Orbit application assets are in [Orbit assets](../../orbit/assets/README.md). Tags does not supply platform installation resources. Use the product names and presentation rules in [brand identity](../../../docs/branding.md).
