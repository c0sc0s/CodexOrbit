# Home greeting fonts

The greeting uses Doto with its roundness axis set to 100. Chinese characters fall back to the round outline edition of ChillBitmap. Both fonts contain complete dot outlines and are embedded in the renderer bundle as data URLs; Home makes no font requests to remote servers.

- `doto-latin-full-normal.woff2`: Doto v3, distributed by `@fontsource-variable/doto` 5.3.0. [Upstream](https://github.com/oliverlalan/Doto). Copyright 2024 The Doto Project Authors. See `Doto-OFL.txt`.
- `chill-bitmap-8px-round.woff2`: [FontPixel's round outline build](https://fontpixel.com/zh/fonts/chill-bitmap/) of [ChillBitmap](https://github.com/Warren2060/ChillBitmap), retrieved October 19, 2026. Copyright 2024 ChillType. See `ChillBitmap-OFL.txt`.
